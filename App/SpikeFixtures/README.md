# Spike 5 fixtures

Synthetic stand-ins written for the spike. They are shaped like PopClip module extensions with a
population function (`module.exports.actions`), and are not taken from any real extension: the
frozen corpus only arrives in M2. Deleted with SpikeLab when M0 closes.

| File | Stands for |
|---|---|
| `small.js` | The common case: a few lines that look at the text and offer one or two actions. |
| `regex.js` | A detector-style extension that runs several regular expressions over the whole selection. Without the JIT entitlement JavaScriptCore also interprets regular expressions, so this is the shape most likely to miss the budget. |
| `bench.js` | Not an extension. A CPU benchmark that runs unchanged in the helper and in the `jsc` command-line tool, which has the JIT. |

The third extension fixture, a large bundled source, is generated by `JSHelperSpike` at run time.
